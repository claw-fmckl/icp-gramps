# Spec 1.1 — Project Scaffold

## Goal
Establish the complete project directory structure and all configuration files needed to build and deploy a working (but empty) ICP canister with an embedded React frontend.

## Reference
Model the structure closely after [promptathon-showcase](https://github.com/kristoferlund/promptathon-showcase). Key differences:
- Use `ic-asset-router` (crates.io) instead of `router_library` (local path)
- Project name: `icp-gramps`
- No indexer — data is entered by the user

## Directory Structure

```
icp-gramps/
├── server/                    # Rust canister
│   ├── src/
│   │   ├── lib.rs
│   │   ├── routes/
│   │   │   └── index.rs       # GET / — serves the React SPA index.html
│   │   ├── db/
│   │   │   └── mod.rs         # DB helpers (empty for now)
│   │   └── migrations/        # SQL files (populated in spec 1.2)
│   ├── Cargo.toml
│   ├── build.rs
│   └── server.did
├── src/                       # React frontend
│   ├── main.tsx
│   ├── App.tsx
│   ├── routes/
│   │   └── index.tsx          # Home route — placeholder "icp-gramps" heading
│   └── vite-env.d.ts
├── specs/                     # RALPH specs (already exists)
├── dfx.json
├── Cargo.toml                 # Workspace manifest
├── package.json
├── pnpm-lock.yaml             # (generated by pnpm install)
├── tsconfig.json
├── vite.config.ts
├── tailwind.config.ts
├── postcss.config.js
├── index.html
├── loop.sh
├── PROMPT.md
├── RALPH.md
└── README.md
```

## Configuration Files

### `dfx.json`
```json
{
  "canisters": {
    "icp_gramps": {
      "candid": "server/server.did",
      "package": "server",
      "build": [
        "pnpm run build",
        "cargo build -p server --target wasm32-wasip1 --release",
        "wasi2ic target/wasm32-wasip1/release/server.wasm target/wasm32-wasip1/release/server_wasi2ic.wasm"
      ],
      "wasm": "target/wasm32-wasip1/release/server_wasi2ic.wasm",
      "type": "custom",
      "metadata": [{ "name": "candid:service" }],
      "declarations": { "bindings": [] }
    }
  },
  "defaults": { "build": { "args": "", "packtool": "" } },
  "output_env_file": ".env",
  "version": 1
}
```

### `Cargo.toml` (workspace root)
```toml
[workspace]
members = ["server"]
resolver = "2"

[profile.release]
lto = true
opt-level = "z"
```

## Acceptance Criteria

- [ ] All config files exist and are syntactically valid
- [ ] `pnpm install` completes without errors
- [ ] `pnpm run build` produces a `dist/` directory
- [ ] `cargo check -p server` passes
- [ ] `cargo build -p server --target wasm32-wasip1 --release` compiles (may take a while first time)
