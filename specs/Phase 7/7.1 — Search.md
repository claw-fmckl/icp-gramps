# Spec 7.1 — Search

## Goal
Full-text search across person names (given names + surname) using SQLite FTS5. A search bar in the nav returns matching persons instantly.

## Backend

### FTS5 maintenance

The `person_fts` virtual table was created in the initial migration. We need to:
1. Populate it on person create/update (insert/update the FTS row)
2. Clean it on person delete
3. Expose a search query

### Update `server/src/db/person.rs`

After `Person::create()` succeeds, insert into FTS:
```sql
INSERT INTO person_fts (person_handle, full_name)
VALUES (?1, ?2)
```
Where `full_name = format!("{} {}", input.given_names, input.surname).trim()`.

After `Person::update()` succeeds, update FTS:
```sql
INSERT INTO person_fts(person_fts, person_handle, full_name) VALUES ('delete', ?1, '');
INSERT INTO person_fts (person_handle, full_name) VALUES (?1, ?2);
```
(FTS5 doesn't have UPDATE — delete + reinsert.)

After `Person::delete()`, remove from FTS:
```sql
INSERT INTO person_fts(person_fts, person_handle, full_name) VALUES ('delete', ?1, '');
```

### New function: `Person::search(query: &str) -> Vec<Person>`

```sql
SELECT p.*
FROM person p
JOIN person_fts f ON f.person_handle = p.handle
WHERE person_fts MATCH ?1
ORDER BY rank
LIMIT 50
```

Append `*` to the query for prefix matching: `format!("{}*", query.trim())`.

### Candid API

```rust
#[query]
fn search_persons(query: String) -> Vec<Person> {
    db::person::Person::search(&query)
}
```

## Frontend

### Search bar in nav — update `src/routes/__root.tsx`

Add a search input to the nav bar (right side). On input change (debounced 300ms), call `search_persons(query)`. Show results in a dropdown below the search bar:
- Each result: full name + Gramps ID, links to `/persons/$handle`
- Empty state: "No results" if query is non-empty and returns nothing
- Clear on blur or result click

### Search results page — `src/routes/search.tsx` (optional)

If user presses Enter, navigate to `/search?q=query` and show full results page with the same person list table as `/persons`.

## Acceptance Criteria

- [ ] FTS5 index is updated on person create, update, delete
- [ ] `search_persons(query)` returns matching persons
- [ ] Prefix search works ("Sven" matches "Svensson")
- [ ] Nav search bar shows live dropdown results
- [ ] Clicking a result navigates to person detail
- [ ] `pnpm run build` and `tsc --noEmit` pass
