# Spec 6.1 — Search

## Goal
Full-text search across person names using the FTS5 virtual table (`person_fts`) already created in the schema. Search results link to person detail pages. Search bar lives in the nav.

## Backend

### FTS index maintenance — `server/src/db/person.rs`

The `person_fts` FTS5 table must be kept in sync with `person_name`. Add helpers:

```rust
/// Insert/update a person's name in the FTS index.
pub fn fts_upsert(conn: &mut Connection, person_handle: &str, full_name: &str) {
    // DELETE existing entry first (FTS5 doesn't have upsert)
    conn.execute(
        "DELETE FROM person_fts WHERE person_handle = ?1",
        [person_handle],
    ).ok();
    conn.execute(
        "INSERT INTO person_fts (person_handle, full_name) VALUES (?1, ?2)",
        [person_handle, full_name],
    ).ok();
}

/// Remove a person from the FTS index.
pub fn fts_delete(conn: &mut Connection, person_handle: &str) {
    conn.execute(
        "DELETE FROM person_fts WHERE person_handle = ?1",
        [person_handle],
    ).ok();
}
```

Call `fts_upsert` in `Person::create` and `Person::update`.
Call `fts_delete` in `Person::delete`.

The `full_name` should be: `format!("{} {} {}", title_text.unwrap_or_default(), given_names, surname).trim().to_string()`

### Search function — `server/src/db/person.rs`

```rust
pub fn search(query: &str) -> Vec<Person> {
    with_connection(|conn| {
        // FTS5 query with prefix matching: append * for prefix search
        let fts_query = format!("{}*", query.trim());
        let mut stmt = conn.prepare(
            "SELECT p.handle, p.gramps_id, p.gender, p.given_names, p.call_name,
                    p.surname, p.suffix, p.title_text, p.birth_ref_handle,
                    p.death_ref_handle, p.private, p.change_date, p.created_at
             FROM person_fts f
             JOIN person p ON p.handle = f.person_handle
             WHERE person_fts MATCH ?1
             ORDER BY rank
             LIMIT 50"
        ).unwrap();
        stmt.query_map([&fts_query], |row| Ok(Person { /* map fields */ }))
            .unwrap()
            .filter_map(|r| r.ok())
            .collect()
    })
}
```

### Candid API

```rust
#[query]
fn search_persons(query: String) -> Vec<db::person::Person> {
    db::person::Person::search(&query)
}
```

### HTTP route — `server/src/routes/api/search.rs`

`GET /api/search?q=smith` → returns JSON array of persons matching the query.

Read from `ctx.query` (untyped map): `ctx.query.get("q").cloned().unwrap_or_default()`.

## Frontend

### Search bar — `src/components/SearchBar.tsx`

- Text input with magnifying glass icon
- On submit (Enter or button click): navigate to `/search?q=<query>`
- Place in the nav bar (right side)

### Search results page — `src/routes/search.tsx`

- Reads `q` from search params
- Fetches `search_persons(q)` via Candid
- Displays results as a table: Name | Gender | Gramps ID — each row links to `/persons/$handle`
- Empty state: "No results for '...'"
- Loading state

**Route file:** `src/routes/search.tsx` with `SearchParams = { q?: string }`

export const Route = createFileRoute('/search')({
