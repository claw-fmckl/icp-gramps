# Spec 6.1 — Places

## Goal
Replace `place_text` free-text fields on events with proper Place entities. Places have a name, type (city, county, country, etc.), and optional lat/long coordinates. Events link to places via `place_handle`. The EventForm gets an autocomplete/text place picker.

## Backend

### Place Model — `server/src/db/place.rs`

```rust
#[derive(Debug, Clone, Serialize, Deserialize, CandidType)]
pub struct Place {
    pub handle:      String,
    pub gramps_id:   String,
    pub title:       String,   // full display title, e.g. "Stockholm, Sweden"
    pub name:        String,   // short name, e.g. "Stockholm"
    pub place_type:  String,   // "city" | "county" | "state" | "country" | "parish" | "unknown"
    pub latitude:    Option<f64>,
    pub longitude:   Option<f64>,
    pub code:        Option<String>,  // postal code, FIPS, etc.
    pub private:     bool,
    pub change_date: i64,
    pub created_at:  i64,
}

#[derive(Debug, Clone, Serialize, Deserialize, CandidType)]
pub struct PlaceInput {
    pub title:      String,
    pub name:       Option<String>,
    pub place_type: Option<String>,
    pub latitude:   Option<f64>,
    pub longitude:  Option<f64>,
    pub code:       Option<String>,
    pub private:    Option<bool>,
}
```

Implement `Place::create`, `Place::get`, `Place::list`, `Place::update`, `Place::delete`, `Place::search(query: &str) -> Vec<Place>` (simple LIKE search on title/name for the picker).

### Event model update

Update `EventInput` to use `place_handle: Option<String>` alongside existing `place_text`. In the `create` and `update` functions, if `place_handle` is provided, also set `event.place_handle = place_handle`. Keep `place_text` for backward compatibility (already-created events).

Add `Event::get_with_place` that returns the event plus joined place title (for display).

### Candid API

```rust
#[query]  fn list_places() -> Vec<Place>
#[query]  fn get_place(handle: String) -> Option<Place>
#[query]  fn search_places(query: String) -> Vec<Place>
#[update] async fn create_place(input: PlaceInput) -> Option<Place>
#[update] fn update_place(handle: String, input: PlaceInput) -> Option<Place>
#[update] fn delete_place(handle: String) -> bool
```

## Frontend

### Place list — `src/routes/places/index.tsx`
Table: Title | Type | Lat/Long | Actions

### New place form — `src/routes/places/new.tsx`
Fields: title (required), name, place_type (select), latitude, longitude, code.

### Place detail — `src/routes/places/$handle.tsx`
Show all fields. Edit/Delete buttons.

### Update EventForm — `src/components/EventForm.tsx`
Replace `place_text` input with a two-part field:
- Text input that searches places as you type (calls `search_places()`)
- Shows matching places as a dropdown list
- On select, sets `place_handle`; clears `place_text`
- "Create new place" link if no match

### Nav update
Add "Places" link.
