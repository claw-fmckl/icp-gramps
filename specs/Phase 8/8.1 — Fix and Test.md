# Spec 8.1 — Fix Compilation Errors + E2E Tests

## Goal
Fix all Rust compilation errors so `dfx deploy` succeeds, then add a pocket-ic E2E test suite that deploys the real canister WASM and validates core endpoints.

## Part 1: Fix Compilation Errors

### 1. `build.rs` — wrong ic-sql-migrate API (ALREADY FIXED)
Already corrected. Verify it reads:
```rust
fn main() {
    ic_asset_router::build::generate_routes();
    ic_sql_migrate::Builder::new()
        .with_migrations_dir("src/migrations")
        .build()
        .unwrap();
}
```

### 2. `server/src/lib.rs` — wrong `include_dir!` path
`$CARGO_MANIFEST_DIR` = `server/`. Change:
```rust
// WRONG:
static DIST_DIR: Dir = include_dir!("$CARGO_MANIFEST_DIR/../../dist");
// CORRECT:
static DIST_DIR: Dir = include_dir!("$CARGO_MANIFEST_DIR/../dist");
```

### 3. `server/src/lib.rs` — `with_connection` closure type
`with_connection` takes `FnOnce(RefMut<'_, Connection>)`. Remove explicit type annotation:
```rust
// WRONG:
with_connection(|conn: &mut Connection| { ... })
// CORRECT:
with_connection(|conn| { ... })
```
Apply this fix everywhere `with_connection` is used across all db modules.

### 4. `server/src/routes/index.rs` — wrong `include_str!` path
File is at `server/src/routes/index.rs`. The dist/ dir is at project root.
```rust
// WRONG:
let html = include_str!("../../dist/index.html");
// CORRECT (3 levels up from routes/ to project root):
let html = include_str!(concat!(env!("CARGO_MANIFEST_DIR"), "/../dist/index.html"));
```

### 5. `rusqlite::params!` — not in scope
`rusqlite` is not a direct dependency. Replace ALL occurrences of `rusqlite::params![...]` with tuple syntax:
```rust
// WRONG:
conn.execute(sql, rusqlite::params![a, b, c])
// CORRECT:
conn.execute(sql, (a, b, c))
// For single params:
conn.execute(sql, (a,))
// For no params:
conn.execute(sql, [])
```
Apply across all files in `server/src/db/`.

### 6. `Cow::Borrowed(b"...")` — array vs slice type mismatch
`b"text"` is `&[u8; N]`. The `with_body()` method needs `&[u8]`:
```rust
// WRONG:
.with_body(Cow::Borrowed(b"{\"error\":\"Not found\"}"))
// CORRECT:
.with_body(b"{\"error\":\"Not found\"}" as &[u8])
```
Apply across all route handler files.

### 7. Dynamic route params access
For `server/src/routes/api/persons/_handle/index.rs`, the build script generates a typed params struct. The handle field is accessed as `ctx.params.handle` (a `String`), not `ctx.params.get("handle")`:
```rust
// WRONG:
let handle = ctx.params.get("handle").unwrap_or("");
// CORRECT — params is a generated struct with .handle field:
let handle = &ctx.params.handle;
```
The route context for `_handle` routes has type `RouteContext<Params>` where `Params` is auto-generated with a `pub handle: String` field. Check the generated `__route_tree.rs` in OUT_DIR for the exact struct name if needed.

### 8. Add `rusqlite` as direct dev dependency (for type inference)
In `server/Cargo.toml`, add under `[dependencies]`:
```toml
rusqlite = { version = "0.37", features = ["bundled"] }
```
This allows `use rusqlite::Row` etc. in db modules. ic-rusqlite re-exports rusqlite but for cleaner imports it's better to depend on it directly.

**Actually** — do NOT add rusqlite separately. Instead, use `ic_rusqlite::rusqlite` re-export where needed:
```rust
use ic_rusqlite::rusqlite; // then rusqlite::params! works
// OR just use tuple syntax (preferred, no import needed)
```

### WASM path constant
The test suite needs the deployed WASM. After `cargo build -p server --target wasm32-wasip1 --release && wasi2ic ...`, the WASM lives at:
```
target/wasm32-wasip1/release/server_wasi2ic.wasm
```

### `tests/e2e/src/lib.rs`

```rust
#[cfg(test)]
mod tests {
    use candid::Principal;
    use pocket_ic::PocketIc;
    use reqwest::blocking::Client;
    use serde_json::{json, Value};
    use std::time::Duration;

    const WASM_PATH: &str = concat!(
        env!("CARGO_MANIFEST_DIR"),
        "/../../target/wasm32-wasip1/release/server_wasi2ic.wasm"
    );

    fn setup() -> (PocketIc, Client, String, Principal) {
        let mut pic = PocketIc::new();
        let canister_id = pic.create_canister();
        pic.add_cycles(canister_id, 2_000_000_000_000);

        let wasm = std::fs::read(WASM_PATH)
            .expect("WASM not found — run: pnpm run build && cargo build -p server --target wasm32-wasip1 --release && wasi2ic target/wasm32-wasip1/release/server.wasm target/wasm32-wasip1/release/server_wasi2ic.wasm");

        pic.install_canister(canister_id, wasm, vec![], None);
        let gateway_url = pic.make_live(None);
        let port = gateway_url.port().unwrap();

        let client = Client::builder()
            .timeout(Duration::from_secs(30))
            .build()
            .unwrap();

        let base = format!("http://localhost:{}", port);
        (pic, client, base, canister_id)
    }

    fn url(base: &str, path: &str, canister_id: Principal) -> String {
        format!("{}{}?canisterId={}", base, path, canister_id)
    }

    // --- Homepage ---

    #[test]
    fn test_homepage_returns_200() {
        let (_pic, client, base, cid) = setup();
        let resp = client.get(url(&base, "/", cid)).send().unwrap();
        assert_eq!(resp.status().as_u16(), 200);
        let body = resp.text().unwrap();
        assert!(body.contains("icp-gramps"), "homepage should contain 'icp-gramps'");
    }

    // --- Person CRUD ---

    #[test]
    fn test_person_list_empty() {
        let (_pic, client, base, cid) = setup();
        let resp = client.get(url(&base, "/api/persons", cid)).send().unwrap();
        assert_eq!(resp.status().as_u16(), 200);
        let body: Value = resp.json().unwrap();
        assert!(body.is_array(), "should return JSON array");
        assert_eq!(body.as_array().unwrap().len(), 0, "should be empty initially");
    }

    #[test]
    fn test_create_and_get_person() {
        let (_pic, client, base, cid) = setup();

        // Create
        let create_resp = client
            .post(url(&base, "/api/persons", cid))
            .json(&json!({
                "given_names": "Erik",
                "surname": "Svensson",
                "gender": 1,
                "call_name": null,
                "title_text": null,
                "suffix": null,
                "private": false
            }))
            .send()
            .unwrap();
        assert_eq!(create_resp.status().as_u16(), 201);
        let person: Value = create_resp.json().unwrap();
        let handle = person["handle"].as_str().expect("handle missing");
        assert_eq!(person["given_names"], "Erik");
        assert_eq!(person["surname"], "Svensson");
        assert!(person["gramps_id"].as_str().unwrap().starts_with('I'));

        // Get by handle
        let get_resp = client
            .get(url(&base, &format!("/api/persons/{}", handle), cid))
            .send()
            .unwrap();
        assert_eq!(get_resp.status().as_u16(), 200);
        let fetched: Value = get_resp.json().unwrap();
        assert_eq!(fetched["handle"], person["handle"]);
    }

    #[test]
    fn test_update_person() {
        let (_pic, client, base, cid) = setup();

        // Create
        let create_resp = client
            .post(url(&base, "/api/persons", cid))
            .json(&json!({"given_names": "Anna", "surname": "Larsson", "gender": 2, "private": false}))
            .send().unwrap();
        let person: Value = create_resp.json().unwrap();
        let handle = person["handle"].as_str().unwrap();

        // Update
        let update_resp = client
            .put(url(&base, &format!("/api/persons/{}", handle), cid))
            .json(&json!({"given_names": "Anna-Lena", "surname": "Larsson", "gender": 2, "private": false}))
            .send().unwrap();
        assert_eq!(update_resp.status().as_u16(), 200);
        let updated: Value = update_resp.json().unwrap();
        assert_eq!(updated["given_names"], "Anna-Lena");
    }

    #[test]
    fn test_delete_person() {
        let (_pic, client, base, cid) = setup();

        let create_resp = client
            .post(url(&base, "/api/persons", cid))
            .json(&json!({"given_names": "Lars", "surname": "Test", "gender": 1, "private": false}))
            .send().unwrap();
        let person: Value = create_resp.json().unwrap();
        let handle = person["handle"].as_str().unwrap();

        let del_resp = client
            .delete(url(&base, &format!("/api/persons/{}", handle), cid))
            .send().unwrap();
        assert_eq!(del_resp.status().as_u16(), 200);

        // Should 404 now
        let get_resp = client
            .get(url(&base, &format!("/api/persons/{}", handle), cid))
            .send().unwrap();
        assert_eq!(get_resp.status().as_u16(), 404);
    }

    #[test]
    fn test_get_nonexistent_person_returns_404() {
        let (_pic, client, base, cid) = setup();
        let resp = client
            .get(url(&base, "/api/persons/doesnotexist", cid))
            .send().unwrap();
        assert_eq!(resp.status().as_u16(), 404);
    }

    // --- Static assets ---

    #[test]
    fn test_static_js_asset() {
        let (_pic, client, base, cid) = setup();
        // The Vite build produces assets/index-*.js — check the assets/ path returns something
        let resp = client.get(url(&base, "/assets/", cid)).send().unwrap();
        // Either 200 (directory listing) or 404 is acceptable; just ensure no 500
        assert_ne!(resp.status().as_u16(), 500);
    }
}
```

### Build script for tests
Add a `build.rs` to `tests/e2e/`:
```rust
fn main() {
    // Tell cargo to rebuild tests if the WASM changes
    println!("cargo:rerun-if-changed=../../target/wasm32-wasip1/release/server_wasi2ic.wasm");
}
```

### Running tests

First build the WASM:
```bash
cd ~/gh/icp-gramps

source ~/.cargo/env

wasi2ic target/wasm32-wasip1/release/server.wasm target/wasm32-wasip1/release/server_wasi2ic.wasm
```

Then run tests:
```bash
cargo test -p e2e-tests 2>&1
```
