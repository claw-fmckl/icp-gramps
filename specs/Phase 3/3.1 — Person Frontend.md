# Spec 3.1 — Person Frontend

## Goal
React pages for browsing, viewing, adding, and editing persons. Data fetched from the Candid API via `@dfinity/agent`.

## Dependencies

Add to `package.json`:
```json
{
  "dependencies": {
    "@dfinity/agent": "latest",
    "@dfinity/candid": "latest",
    "@dfinity/principal": "latest"
  }
}
```

## Canister Actor Hook

Create `src/hooks/useActor.ts` — returns a typed IC actor for the canister.
The canister ID is read from `import.meta.env.VITE_CANISTER_ID_ICP_GRAMPS` (set in `.env` by dfx).

## Routes

### `/persons` — Person list
File: `src/routes/persons/index.tsx`

- Fetches `list_persons()` from Candid API
- Displays a table: Name | Gender | Birth | Death | Actions
- Gender shown as icon: ♂ (male), ♀ (female), ? (unknown/other)
- Name is a link to `/persons/$handle`
- "Add person" button links to `/persons/new`
- Loading state with spinner

### `/persons/new` — Add person form
File: `src/routes/persons/new.tsx`

Fields:
- Given names (text input, required)
- Surname (text input)
- Gender (select: Unknown / Male / Female / Other)
- Call name (text input, optional)
- Title (text input, optional, e.g. "Dr.", "Rev.")
- Suffix (text input, optional, e.g. "Jr.", "III")
- Private (checkbox)

Submit calls `create_person()`. On success, navigate to `/persons/$handle`.

### `/persons/$handle` — Person detail
File: `src/routes/persons/$handle.tsx`

Display:
- Full name (title + given + surname + suffix) as `<h1>`
- Gender icon
- Call name (if set): "Known as: ..."
- Gramps ID (small gray text)
- Birth info section (event date + place — populated in Phase 4)
- Death info section (event date + place — populated in Phase 4)
- "Edit" button → `/persons/$handle/edit`
- "Delete" button → confirmation dialog → `delete_person()` → redirect to `/persons`
- Parents section (populated in Phase 5)
- Families/Spouses section (populated in Phase 5)

### `/persons/$handle/edit` — Edit person form
File: `src/routes/persons/$handle/edit.tsx`

Same fields as new form, pre-populated from `get_person()`.
Submit calls `update_person()`. On success, navigate back to `/persons/$handle`.

## Shared Components

`src/components/GenderIcon.tsx` — renders ♂/♀/? based on gender integer
`src/components/PersonName.tsx` — formats full name from parts
`src/components/LoadingSpinner.tsx` — generic loading indicator
